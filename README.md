# 傲視小助手

第二版（v2.0）｜發佈日期：2026-10-09

## 版本內容

本版本提供完整程式包，包含主程式、全部 DLL、runtimes、使用說明及 Windows 11 Flash ActiveX 移植操作文件。

- 更新傲視小助手.exe 與 astdcommon.dll。
- 包含 NianAutomation.dll、TraditionalUiRuntime.dll、LogPageRepaint.dll 及其他執行所需元件。
- 包含 Win10_Flash_ActiveX_移植到_Win11_操作過程.docx。
- SHA256SUMS.txt 提供程式檔案及操作文件的校驗值。

## 下載與使用

1. 到 [第二版 Release](https://github.com/yoyo50035/aoshi-assistant-backup/releases/tag/v2.0) 下載 aoshi-assistant-v2.0.zip。
2. 完整解壓縮並保持目錄結構，EXE、DLL、.config 與 runtimes 需放在同一程式資料夾。
3. 執行「傲視小助手.exe」。Windows 11 Flash ActiveX 環境設定請參閱隨附操作文件。

## 更新方式

每次更新均提供完整程式包，包含全部 DLL；請在關閉程式後解壓縮全部內容進行更新。更新前請保留自己的 account.ini 與 accounts 資料夾。
